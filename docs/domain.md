# 领域说明

会费、赞助、工资税费、赛事报名和家长退款形成不同期限的现金流，闲置余额只有在最坏情景下仍有余量时才能投资。预测假设、银行价值日、产品到期日和审批时间要分别记录。冻结资金、情景版本和回款状态属于长期留存的信息。

`reference/domain.json` 保存公开的现金事件、投资状态、情景类型和币种。正式记录使用稳定标识（`INV-xxxx`/`EV-xxxx`/`BE-xxxx`/`AL-xxxx`），并区分业务时间（计划日/价值日）、接收时间（`received_at`）、审批时间（`decided_at`）与假设版本（`assumption_version_at_decision`）。

## 情景

- `base`：已承诺现金流按计划日发生。
- `worst`：赞助延期且打折到账、会费催缴延迟、退款提前且放量、联赛报名费提前扣款、理财到期回款延迟。具体参数为可版本化的预测假设。

## 投资批次状态

`proposed → approved / blocked → settled → matured`

- `approved`/`blocked` 一旦判定即冻结：保存当时假设版本与闸门预测快照，后续假设调整不回溯改写。
- `matured` 由到期回款登记触发；回款允许先于结算乱序到达，同一批次重复回款幂等返回。
